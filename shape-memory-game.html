Shape Memory Game

Project Description

Shape Memory Game is a Java GUI-based memory game where shapes appear one at a time and disappear, requiring the user to remember the full sequence in the correct order. After several shapes are shown, the user enters the order of the shape sequence and submits their answer. If the submitted sequence matches the correct order, a win screen is displayed; otherwise, a lose screen is shown. The project also includes a title page, menu screen, instructions page, interactive buttons, input handling, and multiple GUI windows/screens.
